## Estructura de carpetas

El proyecto tiene dos carpetas. La primera carpeta es la carpeta "order-management-system-legacy" que corresponde a una aplicación monolitica legado en Java. La segunda carpeta es "order-management-system-modernized" y corresponde a un experimento de modernización de software sobre la aplicación legado a una aplicación en microservicios con Fast API en Python. Cada carpeta contiene un correspondiente README para las instrucciones de ejecución.

El frontend de la aplicación legado se desarrolló con Lovable con React y se guarda en el siguiente repositorio paralelo: https://github.com/GeraldineGomez/orderly-flow-ui.
